
# 🧠 Jogo de Perguntas e Respostas – Estilo Show do Milhão

Este é um jogo de perguntas e respostas inspirado no "Show do Milhão", desenvolvido com HTML, CSS e JavaScript puro. O objetivo é responder corretamente às perguntas, utilizando ajudas estratégicas: **pular**, **eliminar duas alternativas** ou **parar**.

## 🚀 Como executar o projeto localmente

### Pré-requisitos

- Ter o [Node.js](https://nodejs.org/) instalado.
- Ter o arquivo do projeto salvo em uma pasta local.

🕹️ Como jogar

    Digite seu nome na tela inicial e clique em "Iniciar Jogo".

    Leia a pergunta e escolha uma das alternativas clicando no botão correspondente.

    Você pode usar as seguintes ajudas:

        🟡 Pular: pula para a próxima pergunta. Limite: 2 vezes.

        🔴 Eliminar 2: remove duas alternativas erradas. Limite: 2 vezes.

        💰 Parar: encerra o jogo com os pontos acumulados até o momento.

    O jogo termina quando:

        Você erra uma pergunta.

        Acerta todas as perguntas.

        Decide parar.

    Após o fim do jogo, clique em "Jogar Novamente" para recomeçar.
